# 页面截图说明

截图建议使用 1600 × 1100 视口，先运行 `./demo.sh` 生成演示数据，再访问 `http://localhost:8000`。

| 序号 | 路由 | 截图内容 |
| --- | --- | --- |
| 01 | `#/overview` | 四张安全指标卡、最近出域事件、实时告警、四失风险收敛图 |
| 02 | `#/assets` | 搜索与分级筛选、5 条种子资产、涉密标记、申请共享入口 |
| 03 | `#/sandbox` | 挂载卷树、深色 Python 编辑器、控制台/文件双 Tab、操作日志时间线 |
| 04 | `#/export` | 状态筛选、出域申请单、四步新建申请弹窗 |
| 05 | `#/approval` | L3/L4 待办、风险提示、右侧审批抽屉与三级审批链 |
| 06 | `#/trace` | 已导出文件表、按水印 ID/上传文件查询入口、七步时间线与匹配度 |
| 07 | `#/audit` | 审计筛选、阻断记录红色高亮、右侧风控统计卡 |
| 08 | `#/components` | 6 个组件状态卡、Mock/Docker/OpenSandbox 候选探测、修复建议与闭环自检入口 |

这些页面均由单页应用实时调用 API 渲染，不使用静态假数据。
